## About

Athalea builds software and computing infrastructure for science. We work at the intersection of research and engineering, developing tools that make scientific work faster, more reproducible, and easier to scale.

## What we work on

- **Research software:** tools and libraries designed around real scientific workflows.
- **Scientific computing:** high-performance and GPU computing, workflow orchestration, and cluster infrastructure.
- **Data infrastructure:** systems for managing, processing, and monitoring research data.
